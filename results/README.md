## 全市場資料收集（已完成）

| 檔案 | 內容 |
|---|---|
| `collect_summary.md` | `collect_data.py` 的執行期間、各資料集抓取率（上市中／已下市）、合併後列數與日期範圍、收集後發現的問題、全市場 Demo 總表統計。只有彙總數字，原始資料依 FinMind 授權不上傳 |
| `dataset_summary.csv` | 正式資料集（`build_dataset.py`，2026-11-14）各特徵年的統計：母體、上市未滿一年／興櫃／流動性排除筆數、流動性門檻、可排名筆數、`y_raw`、`y_main` 正例與 UNKNOWN 筆數、正例率。只有統計數字，不含原始資料 |
| `rule_thresholds.csv` | 兩條領域規則（`rules.py`）在三輪 walk-forward 的門檻（只用訓練特徵年的特徵分布）與訓練期觸發率、不適用率。不含標記或報酬 |
| `train_summary.csv` | 模型訓練（`train.py`，2026-11-18）三輪 walk-forward 的筆數：訓練特徵年、訓練筆數（`y_main` 可判定）、訓練正例與正例率、排除的 UNKNOWN、訓練標記最晚揭曉日、測試特徵日、測試評分筆數、測試可判定與正例筆數、訓練沒看過的產業數。**不含模型分數或任何排序指標**（待 `evaluate.py`） |
| `e1_ranking.csv` | 實驗 E1（`evaluate.py`，2026-11-18）：三輪各方法（LightGBM、邏輯迴歸、低 P/B、高 ROE、Yartseva 啟發規則、隨機 1,000 次平均）的 Precision@20/50、Recall@50、PR-AUC，可評估筆數、正例、基準正例率、無法評分筆數。方法定義見 DESIGN 11.5 |
| `e1_random.csv` | E1 隨機基準 1,000 次（種子 42）的指標分布：平均、第 5／50／95 百分位 |
| `e2_portfolio.csv` | 實驗 E2（`evaluate.py`，2026-11-18）：三輪 LightGBM 前 50、邏輯迴歸前 50、隨機 50 檔（1,000 次平均與第 5／95 百分位）、0050 的 5 年累積含息報酬（毛報酬，未計交易成本）與最大回撤，以及進出場日、期間下市、價格異常、延後進場筆數。只有組合層級的數字，不含個股報酬 |
| `e3_quintile.csv` | 實驗 E3（2026-11-18）五等分正例率：10 項特徵各自在每個特徵年內分五等分（缺值另成一組），2013–2020 合併的筆數、`y_main` 正例、正例率、對基準倍數，以及 8 年中 Q5 正例率高於 Q1 的年數 |
| `e3_groups.csv` | E3 三組（主要正例、高報酬但營收未過門檻、其餘可判定）依期間下市分層的特徵中位數與筆數；`y_main` UNKNOWN 筆數；各特徵年 0050 同期含息報酬 |
| `e3_shap.csv` | E3 LightGBM SHAP（內建 `pred_contrib`）：三輪測試年各特徵的平均 \|SHAP\|、名次、特徵值與 SHAP 的 Spearman 相關 |
| `shares_crosscheck.csv` | 市值改用發行股數後（2026-11-14），與原本「股本 ÷ 10 再修正減資、分割」相差超過 20% 的 64 筆「公司 × 年份」：兩種算法的市值（億元）與比值。只有計算後的市值，不含原始資料 |
| `return_crosscheck.csv` | 含息報酬與 Yahoo 股市還原股價的抽樣核對（8 檔）：本專題算出的 5 年含息報酬（當時以 60 日終點平均計算，DESIGN v0.6 起正式改為 20 日；核對對象是公司行動因子，與終點天數無關）、只看股價報酬、Yahoo 還原股價報酬與差異原因。只有計算後的報酬數字，不含原始股價 |
