# Multibagger Scout（台股潛力股偵察員）

**Multibagger Scout: A Point-in-Time AI Agent for Identifying Potential High-Return Stocks in Taiwan**

使用者輸入一家台灣上市公司，Agent 只使用「當時已公告」的公開資料，判斷它未來 5 年是否具備「暴漲股」特徵，並用歷史相似案例與財報證據說明理由。

> **免責聲明**：本專題為大學課程的研究與教學用途，所有輸出皆不構成任何投資建議。投資有風險，請自行判斷。

完整系統設計請見 **[DESIGN.md](DESIGN.md)**。

## 這個專案在做什麼

### 一句話

> 回到過去任何一年的 4 月底，只看「當時大家都看得到」的財報和股價，找出哪些台股公司在接下來 5 年最有可能大漲，並且說清楚為什麼。

### 要解決的問題

「暴漲股」（multibagger）指的是幾年內股價翻好幾倍的公司。研究發現，股市的長期報酬集中在極少數這類股票上，所以如果能提早找到它們的共同特徵，對投資人和財金教學都有幫助。

但事後回頭看，很容易覺得「當初明明看得出來」。實際上，常見的選股分析有四個陷阱：

| 陷阱 | 例子 | 本專題怎麼避免 |
|---|---|---|
| **偷看未來** | 用 2015 年的資料做判斷，卻不小心用到 2015 年 4 月還沒公布的年報 | 財報與月營收只用前一年度（4 月底時一定已公布），股價只用分析日前的交易資料 |
| **只看活下來的公司** | 只分析現在還上市的公司，忽略中途下市的失敗案例，結果看起來特別好 | 樣本包含後來下市的公司 |
| **把炒作當成機會** | 冷門股被少數人拉抬，或剛好在高點結算，報酬看起來很驚人，但公司本身沒有成長 | 暴漲股還必須有營收的實質成長；排除成交量最低 10% 的冷門股；結束價取最後 20 個交易日（約一個月）平均 |
| **AI 亂編數字** | 直接問 ChatGPT「這檔股票會不會漲」，它可能編造財報數字，或憑記憶「知道」後來的結果 | 數字全部由程式計算，AI 只負責解釋，而且報告中的數字會自動核對 |

### 使用者會拿到什麼

在網頁輸入**股票代號**和**分析日期**，系統會產生一份分析報告，例如（格式示意，非實際結果）：

```
【分析對象】某公司（代號 XXXX）　分析日：20XX-04-30

潛力等級：中高
模型分數：0.XX（訓練期正例率 X%）

✅ 支持的證據
   - 年營收成長率高於全市場 XX% 的公司
   - 自由現金流殖利率偏高，股價相對便宜

⚠️ 反對的證據
   - 營業現金流遠低於淨利，獲利可能不是真的現金

📚 歷史上的相似案例
   - 成功：公司 A（20XX 年）→ 5 年後成為基本面驅動暴漲股
   - 失敗：公司 B（20XX 年）→ 特徵相似，但沒有大漲

❓ 不確定性：歷史上特徵相似的案例不多，判斷依據有限
```

使用者也可以繼續追問，例如「為什麼營業現金流低於淨利是警訊？」。如果時間允許，網站會再加上**全市場篩選**（列出某年模型分數最高的公司）和**回測成果**兩個頁面（延伸目標）。

> **關於分析日期**：系統以每年 **4 月底**為判斷時點（前一年年報已全部公告）。輸入其他日期時，會自動退回「不晚於該日的最近一個 4 月底」，例如輸入 2024-10-15，實際以 2024-04-30 的資料分析。
>
> **關於相似案例**：案例的結果要 5 年後才知道，所以只會從「分析日往前 5 年以上」的歷史中找。資料從 2013 年開始，分析日早於 2018 年 4 月時不會顯示相似案例。

### 系統怎麼運作

```
① 收集資料 → ② 計算特徵 → ③ 模型預測 → ④ 找證據 → ⑤ AI 寫報告 → ⑥ 數字核對
```

1. **收集資料**：從 FinMind 抓所有上市公司（含已下市）的財報、月營收、股價、除權息資料
2. **計算特徵**：只用前一年度的年報與月營收、分析日前的股價，算出 10 項指標＋產業類別，例如本益比、ROE、年營收成長率、過去一年漲幅
3. **模型預測**：用 LightGBM 算出這家公司成為「未來 5 年報酬前 5%，而且營收有實質成長」的模型分數
4. **找證據**：
   - SHAP：哪些指標把模型分數推高、哪些拉低
   - 相似案例：歷史上指標最像的公司，後來漲了還是沒漲
   - 領域規則：檢查盈餘品質、估值過高兩種警訊，並附上規則說明與文獻出處
5. **AI 寫報告**：大型語言模型（LLM）把上面的結果整理成看得懂的文字
6. **數字核對**：程式檢查報告中的每個數字都和計算結果一致，不一致就重寫

### 怎麼知道它有沒有用

用 2013–2020 年的歷史資料做回測：只用過去的資料訓練模型，再拿它預測「之後」的年份，看預測排名前 20、前 50 名中，有多少家真的成為暴漲股。同時和隨機挑選、單一指標選股、買進持有 0050 等方法比較。詳細實驗設計見 [DESIGN.md](DESIGN.md) 第 11 節。

### 名詞小辭典

| 名詞 | 意思 |
|---|---|
| 暴漲股（multibagger） | 本專題定義為：未來 5 年含息報酬排名全體上市股票**前 5%**，**而且**同期營收年複合成長 ≥ 10% 的公司（延伸目標會再加入 EPS 條件）。只看報酬前 5% 的版本作為對照 |
| 基準率 | 訓練期資料中暴漲股所占的比例；模型分數要和它比，才知道高不高（評估時改用同輪可評估母體的實際正例率） |
| 含息報酬 | 股價漲跌加上配息配股，並假設股利再投入同一檔股票 |
| Point-in-Time（時間一致） | 只使用分析當時已經公開的資料 |
| 回測 | 用歷史資料模擬「如果當時用這個方法，結果會怎樣」 |
| Agent | 能自己規劃步驟、呼叫工具、整合結果的 AI 系統 |

## 快速開始

1. 安裝 **Python 3.10 以上**
2. 下載專案並安裝套件：

   ```bash
   git clone https://github.com/yui000130/AIoT-FinalProject-MultibaggerScout-AIagent.git
   cd AIoT-FinalProject-MultibaggerScout-AIagent
   pip install -r requirements.txt
   ```

3. （選用）設定 API Token：把 `.env.example` 複製成 `.env`，填入 FinMind Token。
   不註冊也能執行（免費額度約每小時 300 次）；註冊後約每小時 600 次。

   **取得 Token**：到 [FinMind 官網](https://finmindtrade.com/) 免費註冊並登入，在會員頁面複製 API Token。
   API 使用說明請見 [FinMind 文件](https://finmind.github.io/)。

   ```bash
   cp .env.example .env      # Windows PowerShell：Copy-Item .env.example .env
   ```

   > `.env` 已被 `.gitignore` 排除，**請勿上傳到 GitHub**。

4. 執行資料驗證：

   ```bash
   python verify_data.py
   ```

   約使用 215 次 API。抓過的資料會快取在 `cache/`，重跑不會再花次數；如果中途次數用完，一小時後重跑會接著抓。

5. （選用）開啟 Demo 網頁：見上方 [Demo 網頁](#demo-網頁)。
